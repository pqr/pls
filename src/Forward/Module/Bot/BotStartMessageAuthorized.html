Для поиска доступны следующие команды: mawb номер - поиск по номеру накладной cont номер_контейнера - поиск по номеру контейнера truck номер_машины - поиск по номеру машины В номере MAWB, контейнера и машины можно указать лишь часть номера month месяц - пример поиска за декабрь: month 12/2017 Если поиск осуществляется в текущем году, то для краткости можно опустить номер года: month 12 Можно указать интервал месяцев, пример поиска с октября по декабрь включительно: month 10/2017-12/2017 или кратко month 10-12 cs менеджер - поиск по ответсвенному Customer Service, можно указать фрагмент имени или логина, например: cs дзю или cs dzu cs me - особая форма, которая покажет все "свои" перевозки cust клиент - поиск по клиенту (фрагмент имени Customer или Customer Account) file номер_файла - показать детали по конкретной перевозке по File Numner Если просто указать какое-то слово без команды, то будет выполнен поиск в номерах MAWB, контейнеров и в номерах машин - удобно, когда нужно быстро что-то найти не хочется вводить команды, например: 580-14582606 - будет произведён поиск "580-14582606" в номерах MAWB, контейнеров и машин, скорее всего найдётся како-то результат по номеру MAWB MSKU1234567 - будет произведён поиск "MSKU1234567" в номерах MAWB, контейнеров и машин, скорее всего найдётся како-то результат по номеру контейнера A555X - будет произведён поиск "A555X" в номерах MAWB, контейнеров и машин, скорее всего найдётся како-то машина содержащая этот текст в номере Команды можно комбинировать, примеры: month 12 cust Sport - показать все перевозки клиента с именем содеражщем "Sport" за декабрь текущего года cust Sport month 10/2017-12/2017 - показать все перевозки клиента с именем содеражщем "Sport" за три месяца (с октября по декабрь 2017)
